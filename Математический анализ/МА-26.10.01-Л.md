# Предел функции

*Обозначения.* $X \subset \mathbb{R}$ — область определения функции $f$; $a, A \in \mathbb{R}$. Квантор $\forall$ — «для любого», $\exists$ — «существует».

---

## 1. Окрестности

### Определение. δ-окрестность точки

> Пусть $a \in \mathbb{R}$, $\delta > 0$. **δ-окрестностью** точки $a$ называется интервал
> $$U_\delta(a) = (a-\delta,\ a+\delta) = \{x : |x-a| < \delta\}.$$

### Определение. Проколотая δ-окрестность точки

> **Проколотой δ-окрестностью** точки $a$ называется δ-окрестность без самой точки $a$:
> $$\mathring{U}\_\delta(a) = U_\delta(a) \setminus \{a\} = (a-\delta,\ a) \cup (a,\ a+\delta) = \{x : 0 < |x-a| < \delta\}.$$

### Определение. Предельная точка множества

> Точка $a$ называется **предельной точкой** множества $X$, если в любой проколотой окрестности $a$ есть точки $X$:
> $$\forall \delta > 0:\ \mathring{U}_\delta(a) \cap X \neq \varnothing.$$

*Замечание.* Предел функции в точке $a$ рассматривают только когда $a$ — предельная точка $X$. Сама точка $a$ может не принадлежать $X$, а если принадлежит, то значение $f(a)$ на предел не влияет — поэтому окрестность «прокалывают».

---

## 2. Определение предела

### Определение. Предел функции по Коши (в терминах окрестностей)

> Число $A$ называется **пределом функции $f$ в точке $a$** (при $x \to a$), если для любой ε-окрестности точки $A$ найдётся такая проколотая δ-окрестность точки $a$, что образ её пересечения с $X$ лежит в этой ε-окрестности:
> $$\forall \varepsilon > 0\ \ \exists \delta > 0:\ \ f\big(\mathring{U}\_\delta(a) \cap X\big) \subset U_\varepsilon(A).$$
>
> Обозначение: $\displaystyle \lim_{x \to a} f(x) = A$ или $f(x) \to A$ при $x \to a$.

Это определение записывают тремя эквивалентными способами.

### Запись определения Коши через неравенства

> $$\forall \varepsilon > 0\ \ \exists \delta > 0\ \ \forall x \in X:\ \ 0 < |x-a| < \delta \ \Rightarrow\ |f(x) - A| < \varepsilon.$$

### Запись определения Коши через интервалы

> $$\forall \varepsilon > 0\ \ \exists \delta > 0\ \ \forall x \in X:\ \ x \in (a-\delta,\ a) \cup (a,\ a+\delta) \ \Rightarrow\ f(x) \in (A-\varepsilon,\ A+\varepsilon).$$

### Запись определения Коши, смешанная

> Неравенство для аргумента, интервал для значения (или наоборот):
> $$\forall \varepsilon > 0\ \ \exists \delta > 0\ \ \forall x \in X:\ \ 0 < |x-a| < \delta \ \Rightarrow\ f(x) \in (A-\varepsilon,\ A+\varepsilon).$$

### Отрицание определения предела по Коши

> Число $A$ **не является** пределом $f$ в точке $a$, если
> $$\exists \varepsilon_0 > 0\ \ \forall \delta > 0\ \ \exists x \in X:\ \ 0 < |x-a| < \delta \ \text{ и } \ |f(x) - A| \geq \varepsilon_0.$$

### Нахождение δ по определению

> **Задача.** Для заданного $\varepsilon > 0$ указать $\delta = \delta(\varepsilon) > 0$, удовлетворяющее определению.
>
> **Схема.**
> 1. Записать требуемое неравенство $|f(x) - A| < \varepsilon$.
> 2. Преобразовать (оценить сверху) левую часть до вида $C \cdot |x-a|$ или $\le \varphi(|x-a|)$.
> 3. Выразить из полученной оценки $|x-a| < \delta(\varepsilon)$.
> 4. Проверить: при $0 < |x-a| < \delta$ исходное неравенство выполняется.

**Пример 1.** $\displaystyle\lim_{x \to 2}(3x - 1) = 5$.
$|f(x) - 5| = |3x - 6| = 3|x-2| < \varepsilon \iff |x-2| < \varepsilon/3$. Значит, $\delta = \varepsilon/3$.

**Пример 2.** $\displaystyle\lim_{x \to 2} x^2 = 4$.
$|x^2 - 4| = |x-2|\,|x+2|$. Считаем $\delta \le 1$; тогда $|x-2| < 1$, $|x+2| < 5$, и $|x^2-4| < 5|x-2|$. Значит, $\delta = \min\{1,\ \varepsilon/5\}$.

### Определение. Предел функции по Гейне (на языке последовательностей)

> Число $A$ называется **пределом функции $f$ в точке $a$**, если для любой последовательности $(x_n)$, такой что
> - $x_n \in X$,
> - $x_n \neq a$,
> - $x_n \to a$,
>
> соответствующая последовательность значений $f(x_n)$ сходится к $A$:
> $$\forall (x_n):\ x_n \in X,\ x_n \neq a,\ x_n \to a \ \Rightarrow\ f(x_n) \to A.$$

### Теорема. Эквивалентность определений предела по Коши и по Гейне

> Определения предела функции по Коши и по Гейне эквивалентны: число $A$ является пределом $f$ в точке $a$ по Коши тогда и только тогда, когда оно является пределом по Гейне.

**Доказательство.**

*Коши ⇒ Гейне.* Пусть $A$ — предел по Коши, и $(x_n)$ — последовательность, $x_n \in X$, $x_n \ne a$, $x_n \to a$. Возьмём $\varepsilon > 0$ и найдём по Коши $\delta$. Так как $x_n \to a$, найдётся $N$, такое что при $n > N$ выполнено $|x_n - a| < \delta$; при этом $x_n \neq a$, т.е. $0 < |x_n - a| < \delta$. Тогда $|f(x_n) - A| < \varepsilon$ при $n > N$, т.е. $f(x_n) \to A$.

*Гейне ⇒ Коши* (от противного). Пусть $A$ — предел по Гейне, но не по Коши. Тогда по отрицанию определения существует $\varepsilon_0 > 0$, такое что для любого $\delta > 0$ найдётся $x \in X$ с $0 < |x-a| < \delta$ и $|f(x) - A| \ge \varepsilon_0$. Берём $\delta = 1/n$ и получаем $x_n \in X$, $0 < |x_n - a| < 1/n$, $|f(x_n) - A| \ge \varepsilon_0$. Тогда $x_n \to a$, $x_n \ne a$, но $f(x_n) \not\to A$ — противоречие с определением по Гейне. $\blacksquare$

## 3. Свойства пределов

### Свойство 1. Единственность предела

> Если функция $f$ имеет предел в точке $a$, то он единственный.

**Доказательство.** Пусть $\lim_{x\to a} f(x) = A$ и $\lim_{x\to a} f(x) = B$, причём $A \ne B$. Положим $\varepsilon = |A-B|/3 > 0$. По Коши найдутся $\delta_1, \delta_2$ для $A$ и $B$ соответственно. Пусть $\delta = \min\{\delta_1, \delta_2\}$. Так как $a$ — предельная точка $X$, существует $x \in \mathring{U}_\delta(a) \cap X$. Для него
$$|A - B| \le |A - f(x)| + |f(x) - B| < 2\varepsilon = \tfrac{2}{3}|A-B|,$$
что невозможно. Значит, $A = B$. $\blacksquare$

### Свойство 2. Локальная ограниченность

> Если существует $\lim_{x \to a} f(x) = A$, то существуют $\delta > 0$ и константа $M$, такие что
> $$|f(x)| \le M \quad \text{для любого } x \in \mathring{U}_\delta(a) \cap X.$$

**Доказательство.** Возьмём $\varepsilon = 1$ и найдём соответствующее $\delta$. Для $x \in \mathring{U}_\delta(a) \cap X$:
$$|f(x)| \le |f(x) - A| + |A| < 1 + |A|.$$
Положим $M = 1 + |A|$. $\blacksquare$

### Свойство 3. Арифметические операции над пределами

> Пусть существуют $\lim_{x\to a} f(x) = A$ и $\lim_{x\to a} g(x) = B$. Тогда существуют и равны:
> - предел суммы: $\lim_{x\to a} (f+g)(x) = A + B$;
> - предел произведения: $\lim_{x\to a} (f\cdot g)(x) = A \cdot B$;
> - предел частного, если $B \ne 0$: $\displaystyle\lim_{x\to a} \frac{f(x)}{g(x)} = \frac{A}{B}$.

**Доказательство.** Проводится через эквивалентность определений Коши и Гейне и опирается на арифметические свойства пределов последовательностей.

Возьмём произвольную последовательность $(x_n)$: $x_n \in X$, $x_n \ne a$, $x_n \to a$. По Гейне $f(x_n) \to A$ и $g(x_n) \to B$. По арифметике пределов последовательностей:
$$f(x_n) + g(x_n) \to A + B, \qquad f(x_n)\, g(x_n) \to AB.$$
Так как $(x_n)$ произвольна, по Гейне получаем утверждения о сумме и произведении.

Для частного при $B \ne 0$: по определению Коши при $\varepsilon = |B|/2$ найдётся $\delta_0$, такое что $|g(x)| > |B|/2 > 0$ при $x \in \mathring{U}\_{\delta_0}(a) \cap X$, т.е. частное определено в этой окрестности. Тогда для $(x_n)$ как выше все члены, начиная с некоторого номера, лежат в $\mathring{U}_{\delta_0}(a)$, и $g(x_n) \ne 0$; по свойству пределов последовательностей $f(x_n)/g(x_n) \to A/B$. По Гейне получаем требуемое. $\blacksquare$
