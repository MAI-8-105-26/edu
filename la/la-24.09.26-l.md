# Матрицы
## Базисный минор. Ранг.
### Определения
- Минор k-го порядка
	>— определитель матрицы k-го порядка (k ≤ min {m, n}), образованной элементами, стоящими на пересечении произвольно выбранных k строк и k столбцов.
- Базисный минор
	>— минор r-го порядка отличный от нуля, такой что все миноры (r+1)-го порядка не существуют.
- Ранг матрицы
	>— порядок базисного минора.
### Свойства базисного минора и ранга
#### Теоремы
О базисном миноре:
> В произвольной матрице A каждый столбец (строка) является линейной комбинацией столбцов (строк), в которых расположен базисный минор.

Необходимое и достаточное условие равенства нулю определителя:
> Чтобы определитель матрицы был равен нулю, необходимо и достаточно, чтобы один из её столбцов (одна из её строк) был(а) линейной комбинацией остальных её столбцов (строк).

О ранге матрицы:
> Ранг матрицы равен максимальному числу линейно независимых строк этой матрицы.
#### Остальные свойства
1. При элементарных преобразованиях ранг матрицы не меняется.
2. Если одна строка является линейной комбинацией остальных, то её (его) можно вычеркнуть, не изменив при этом ранга
3. rg(A + B) ≤ rg A + rg B
4. rg(A • B) ≤ min {rg A, rg B}
5. Если A — невырожденная, то rg(AB) = rg B

Теоремы о ранге матрицы:
> Пусть ранг матрицы = 0, тогда все строки нулевые => нет линейно независимых строк. Пусть ранг матрицы больше нуля, тогда нужно показать, что r строк линейно независимы, а r+1 уже линейно зависимы.
> Возьмём r строк, входящих в базисный минор. Если бы они были линейно зависимыми, то базисный минор был бы равен нулю, а ранг матрицы < r, следовательно в матрице точно есть r линейно независимых строк.
> Покажем, что любые p строк (p > r) линейно зависимы. Образуем из матрицы A матрицу B из этих p строк, ранг B ≤ p. Каждый минор (r+1)го порядка матрицы B является минором (r+1)-го порядка матрицы A, следовательно ранг B ≤ r.
> rg B ≤ r и r < p => rg B < p => в матрице B хотя бы одна строка не является базисной => она является линейной комбинацией остальных => эти p строк линейно зависимы.
> Замечание: max количество линейно независимых строк = максимальному количеству линейно независимых столбцов. rg A = rg A^T
